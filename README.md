# testnet-archive
Configuration snapshot for a retired proof-of-work network, kept for anyone reproducing old state.

:warning: Support for this network stopped in **December 2022**. Move to a maintained one — [the 2019 generation](https://github.com/example/network-four) or [the 2021 generation](https://github.com/example/network-current).

What replaced the merged networks is described in the developer documentation, and walked through in a conference session that is still online.
